Nice Flight! — Stats screen + home screen additions

Approved 2026-10-11. Built as 1.1.0; the table headers were shortened (Launch / Air / Thermal / Top) and the fourth Stats key is MORE when planes do not all fit.

Every number below is computed from the 240 flights on your X14 (Storm Zen, Bull Nose, Whip Tail), not invented. Screens are X14 size (640×360); the X20 gets the same layout with more rows. Decided so far: thermal hit = max altitude at least one climb size (CFG, 50 ft) above launch; "Avg top" = average max altitude of those flights; all-time only; Throw Trainer unchanged.

4 · What the home screen already had vs. what Stats adds

Home screen (today only): last flight's time, max and launch; nice flights of throws; best height and time. Stats (all time, per plane): throws, nice %, average launch, average air time, thermal hit %, average top in a thermal, and badges by plane. The new home-screen line is the overlap: today's average launch, thermal count and average air time, so a session can be read against the lifetime table.

5 · Edge-case pass

  • decidedThermal definition uses the climb size at viewing time. It is computed from each flight's stored launch and max (max − launch ≥ climb size), so changing the CFG climb size re-sorts history consistently rather than freezing each flight's verdict.
  • decidedUnits. Each flight row carries its unit system; a metric plane's flights are converted to the display unit in the table, so a mixed hangar still adds up. The All row is in the display unit.
  • decidedFumbles never count. Throws under 25 ft are not logged today, so they are not in any denominator. Nice % and thermal % are per logged throw.
  • decidedRenamed model = new plane. Flights are keyed by model name, so renaming a model on the radio starts a new row; the old rows stay under the old name. Acceptable; a merge tool is not worth building.
  • decidedComputed on opening Stats, cached until the next flight lands. 240 rows is nothing; even thousands read in well under a second, and it never runs in flight.
  • decidedAll row only with two or more planes; with one plane the table is that plane alone.
  • askReaching Stats from the recap. The recap's four keys are taken (DISMISS, HISTORY, BADGES, CFG). Stats is reached from the home screen and the long-press menu; is that enough, or should the recap's BADGES key go to Stats › Badges instead?
  • askGreying planes under 5 throws — keep, or show them at full strength?
