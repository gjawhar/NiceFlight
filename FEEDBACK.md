Status: open / fixed (version, date) / won't fix (why).

| 1 | 2026-09-17 | The app launches on the CFG screen. It should just start at the main screen. | fixed 0.1.1, 2026-09-17, unverified in the simulator. Ethos opens a widget's `configure` page as soon as the widget is added to a screen. The `configure` entry is no longer registered; settings stay on the CFG key and the long-press menu. |
| 2 | 2026-09-17 | Macros run in real time; five flights would take about 38 minutes. Compress them. | fixed 0.1.1, 2026-09-17, unverified in the simulator. | 3 | 2026-09-17 | Running the first macro, the screen stays on Idle with "stale telemetry" and RX --. | fixed in the macros 2026-09-17, CONFIRMED in the simulator 2026-09-17 (NiceSim1 replayed as 274 ft / 109 ft launch / 4:08 / not nice, matching the real flight). Pilot's own diagnosis was right: with the sim's throttle centred the template sits in Landing mode, which blocks Launch. Measured with NiceSimDiag: throttle = setAnalog(1), elevator = setAnalog(2), launch = setSwitch(7); sensors are flagged lost within 0.25 s unless RSSI frames keep the link alive. Macros now raise the throttle first, use those indices, stream RSSI + VFR with altitude every 0.1 s, and write log.txt + screenshots into their own folder. |
| 4 | 2026-09-17 | (found while diagnosing #3) A flight whose telemetry link dies and is never braked runs forever and is then lost when the radio is switched off, e.g. hand catch then unplug the plane. | fixed 0.1.2, 2026-09-17. Link gone 30 s with the plane last seen low ends the flight where it was last airborne; link gone 3 min at any height stops the clock where it was last seen. |
